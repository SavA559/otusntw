### DHCP (Dynamic Host Configuration Protocol)

DHCP сервис на маршрутизаторах в офисах Н.Новгород (R13-R14) и Бор (R22-R23) поднят с использованием протокола VRRP (Virtual Router Redundancy Protocol), который позволяет объединить два или более маршрутизатора в виртуальную группу для обеспечения отказоустойчивости шлюза по умолчанию. DHCP-серверы раздают все доступные IP-адреса из настроенных пулов, кроме назначенных статически.

#### Команды для проверки
```
show ip dhcp binding - Выводит список всех выданных IP-адресов
show ip dhcp pool - Показывает статус настроенных пулов адресов
show ip dhcp server statistics - Отображает статистику отправленных и полученных DHCP-пакетов
show ip dhcp conflict - Выводит список обнаруженных конфликтов IP-адресов
show dhcp lease - Проверка аренды на клиенте-интерфейсе
```
