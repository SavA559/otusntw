### OSPF (Open Shortest Path First)
Маршрутизаторы R11, R12, R15, R31, R43 находятся в area 0 - backbone.<br>
Маршрутизатор R16 находится в area 16 и получает только маршрут по умолчанию (totally stub).<br>
На R12 настроена фильтрация маршрутной информации так, что маршрутизатор R17 в area 17 получает все маршруты, кроме маршрутов до сетей area 16 (фильтр LSA type 3).<br>
Маршрутизаторы R13-R14 находятся в area 10. R41-R42 - в area 40.<br>
R15 распространяет информацию о маршруте по умолчанию.<br>
Кроме того динамическая маршрутизация настроена поверх GRE-туннелей. Чтобы перенести маршруты из EIGRP в OSPF, на R21 в режиме конфигурации протокола OSPF настроено: redistribution eigrp 100 subnets
Настройка двух GRE-туннелей и OSPF между R15 (Н.Новгород) с двумя ISP и роутером R21 (Бор) выполняется через создание двух независимых туннельных интерфейсов и разное назначение метрик (стоимости) интерфейсов в OSPF для управления приоритетом каналов.


####  Пример настройки OSPF на R12
```
! Чтобы area 17 не знала об area 16, на R12 создаем PL с запрещением подсети зоны 16 и разрешением всех остальных
ip prefix-list NO-ZONE seq 10 deny 10.1.0.16/30
ip prefix-list NO-ZONE seq 20 permit 0.0.0.0/0 le 32
! Включаем протокол динамической маршрутизации OSPF с идентификатором процесса №1:
router ospf 1
! Задаем уникальный идентификатор роутера в зоне OSPF:
 router-id 1.1.1.12
! И на входе в area 17 применяем созданный PL
 area 17 filter-list prefix NO-ZONE in
 network 10.1.0.4 0.0.0.3 area 0
 network 10.1.0.20 0.0.0.3 area 10
 network 10.1.0.24 0.0.0.3 area 10
 network 10.1.0.28 0.0.0.3 area 17
 network 12.12.12.12 0.0.0.0 area 0
 ```

####  Пример настройки OSPF на R16
```
! Настроим R16 с получением только маршрута по умолчанию
router ospf 1
 router-id 1.1.1.16
! Переводим зону 16 в режим NSSA
 area 16 nssa   ! area 16 nssa no-summary – настраивается только на ABR R11
 network 10.1.0.16 0.0.0.3 area 16
 network 16.16.16.16 0.0.0.0 area 16
!
```
####  Пример настройки OSPF на R11
```
router ospf 1
 router-id 1.1.1.11
! В следующую зону не будут импортироваться суммарные маршруты
 area 16 nssa no-summary
! Включаем анонсирование маршрута по умолчанию в зоне NSSA
 default-information-originate
 network 10.1.0.0 0.0.0.3 area 0
 network 10.1.0.8 0.0.0.3 area 10
 network 10.1.0.12 0.0.0.3 area 10
 network 10.1.0.16 0.0.0.3 area 16
 network 11.11.11.11 0.0.0.0 area 0
```

#### Команды для проверки
```
show ip ospf neighbor - Проверка установления соседства с другими роутерами
show ip ospf interface brief - Краткий статус интерфейсов, на которых запущен OSPF
show ip route ospf - Вывод таблицы маршрутизации, содержащей только маршруты, изученные через OSPF
show ip ospf - Общая информация о процессе OSPF на данном маршрутизаторе
show ip ospf database - База данных состояния каналов (LSDB)
show ip ospf interface [имя_интерфейса] - Подробный статус конкретного интерфейса
show run | sec ospf - вывод настроек конфига из раздела ospf
clear ip ospf [process-id] process - используется для перезапуска процесса OSPF на маршрутизаторе.
```
