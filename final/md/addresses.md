### Адресное пространство проекта с использованием IPv4

Для PtP-линков между маршрутизаторами в офисах будут использоваться /30 подсети с Первым и Третьим октетами соответственно = 10 и 0 (10.x.0.y/30).
Для внешних линков (to Internet) первый октет всегда = 172; Второй октет = номер меньшего роутера; Третий октет = номер большего роутера (172.x.y.0/30).
IP-адрес для Loopback interface имеет вид x.x.x.x/32, где x - номер маршрутизатора на схеме.
