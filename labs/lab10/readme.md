#  __Основные протоколы сети интернет__

###  Задание:

Настроить DHCP и синхронизацию времени в офисе Москва, а также NAT в офисах Москва, CПБ и Чокурдах:
 1. Настроить NAT(PAT) на R14 и R15. Трансляция должна осуществляться в адрес автономной системы AS1001.
 2. Настроить NAT(PAT) на R18. Трансляция должна осуществляться в пул из 5 адресов автономной системы AS2042.
 3. Настроить статический NAT для R20.
 4. Настроить NAT так, чтобы R19 был доступен с любого узла для удаленного управления.
 5. Настроить статический NAT(PAT) для офиса Чокурдах.
 6. Настроить для IPv4 DHCP сервер в офисе Москва на маршрутизаторах R12 и R13. VPC1 и VPC7 должны получать сетевые настройки по DHCP.
 7. Настроить NTP сервер на R12 и R13. Все устройства в офисе Москва должны синхронизировать время с R12 и R13.

###  2. Настройка NAT(PAT) на R18. Трансляция должна осуществляться в пул из 5 адресов AS2042:
###  Пример настройки NAT на роутере R18
```
! Создаем список доступа (ACL) для определения внутренней сети
access-list 18 permit 192.168.96.0 0.0.15.255
! Создаем пул из 5 публичных адресов, указывая стартовый и конечный адрес
ip nat pool POOL-NAT 142.0.0.1 142.0.0.5 netmask 255.255.255.0
!Связываем ACL и пул, включая PAT (за счет ключевого слова overload)
ip nat inside source list 18 pool POOL-NAT overload

! Маркируем интерфейсы подключенные к локальной сети и к ISP
interface e0/0
 ip nat inside
!
interface e0/1
 ip nat inside
!
interface e0/2
 ip nat outside
!
interface e0/3
 ip nat outside
!
```

###  6. Настройка для IPv4 DHCP сервер в офисе Москва на маршрутизаторах R12 и R13:
###  Пример настройки DHCP на роутере R12
```
! Создаем пул адресов, шлюз по умолчанию
ip dhcp pool ONE
 network 192.168.101.0 255.255.255.0
 default-router 192.168.101.254
! Указываем DNS-сервер
 dns-server 8.8.8.8
! Исключаем из раздачи статический IP-адрес шлюза 
ip dhcp excluded-address 192.168.101.254
```

###  7. Настройка NTP сервера на R12 и R13. Все устройства в офисе Москва синхронизируют время с ними:
###  Пример настройки NTP на роутере R12
```
! Настроим корректный часовой пояс
clock timezone MSK 3 0
! Включение роутера в качестве NTP-сервера
ntp master 3
! Обновление аппаратных часов роутера
ntp update-calendar
!

! На устройствах сети используем команду чтобы указать адреса NTP-серверов 
! ntp server 172.4.12.2
! ntp server 172.5.13.2
```


### Команды для проверки
```
show ip nat translations — просмотр текущей таблицы трансляций портов и адресов
show ip nat statistics — проверка общей статистики работы NAT и наполненности пула
clear ip nat translation * — принудительный сброс динамических трансляций
show clock - отображает текущее время программных часов
show clock detail - убедиться, что в качестве источника времени выбран NTP
show ntp status - текущий статус синхронизации и стратум
show ntp associations - детальную информацию о соединениях с NTP-серверами
```
