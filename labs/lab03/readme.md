#  __OSPF. Фильтрация__

###  Задание:

Настроить OSPF в офисе Москва, разделить сеть на зоны и настроить фильтрацию между зонами:
  1. Маршрутизаторы R14-R15 находятся в зоне 0 - backbone.
  2. Маршрутизаторы R12-R13 находятся в зоне 10. Дополнительно к маршрутам должны получать маршрут по умолчанию.
  3. Маршрутизатор R19 находится в зоне 101 и получает только маршрут по умолчанию.
  4. Маршрутизатор R20 находится в зоне 102 и получает все маршруты, кроме маршрутов до сетей зоны 101.

###  Решение:

###  1. Настройка маршрутизаторов R14-R15 в зоне 0.

###  Пример настройки OSPF на ASBR-роутере R14:
```
!
router ospf 1
 router-id 1.1.1.14
 area 101 nssa no-summary
 network 10.12.14.0 0.0.0.255 area 0
 network 10.13.14.0 0.0.0.255 area 0
 network 10.14.19.0 0.0.0.255 area 101
! для передачи внешнего маршрута по умолчанию на ASBR роутере команда
 default-information originate
!
! статический маршрут по-умолчанию
ip route 0.0.0.0 0.0.0.0 172.14.22.2 1 name TO-ISP-R22
!
```


###  2. Настройка ABR-роутеров R12-R13 в зоне 10, с получением дополнительно маршрута по умолчанию.
Для передачи маршрута по умолчанию (статический маршрут до провайдера), на ABR-роутере настроим Not so stubby area (NSSA). Блокируются External LSA (5), ABR конвертирует External LSA (5) в Summary LSA (3) 0.0.0.0/0, Для передачи внешних маршрутов используется NSSA External LSA (7).
###  Пример настройки OSPF на R12:
```
!
router ospf 1
 router-id 1.1.1.12
 area 10 nssa default-information originate
 network 10.12.14.0 0.0.0.255 area 0
 network 10.12.15.0 0.0.0.255 area 0
 network 10.4.12.0 0.0.0.255 area 10
 network 10.5.12.0 0.0.0.255 area 10
!
```


###  3. Настройка маршрутизатора R19 в зоне 101, с получением только маршрута по умолчанию.
Totally NSSA - в дополнение к блокированию External LSA (исключение - default), будет блокироваться и Summary LSA. ABR конвертирует External LSA (5) и Summary LSA (3) в Summary LSA (3) 0.0.0.0/0, Для передачи внешних маршрутов используется NSSA External LSA (7).
```
!
router ospf 1
 router-id 1.1.1.19
 area 101 nssa   //area 1 nssa no-summary – настраивается только на ABR R14
 network 10.14.19.0 0.0.0.255 area 101
!
```


###  4. Настройка маршрутизатора R20 в зоне 102, с получением всех маршрутов, кроме маршрутов до сетей зоны 101.

Т.к. Type 3 LSA создаются ABR, фильтрациию настраиваем на ABR-роутере R15:
```
! Создаем prefix-list с запрещением подсети зоны 101 и разрешением всех остальных
ip prefix-list NO-ZONE seq 10 deny 10.14.19.0/24 ge 24 le 24
ip prefix-list NO-ZONE seq 20 permit 0.0.0.0/0 le 32
!
! На входе в зону 102 применяем созданный prefix-list
area 102 filter-list prefix NO-ZONE in
!
```

###  Пример настройки OSPF на R20:

```
!
router ospf 1
 router-id 1.1.1.20
 network 10.15.20.0 0.0.0.255 area 102
!
```
