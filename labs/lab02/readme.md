#  __Маршрутизация на основе политик (PBR)__

###  Задание:

  1. Настроите политику маршрутизации для сетей офиса.
  2. Распределите трафик между двумя линками с провайдером.
  3. Настроите отслеживание линка через технологию IP SLA.(только для IPv4)
  4. Настройте для офиса Лабытнанги маршрут по-умолчанию.

###  Решение:


###  4. Маршрут по-умолчанию для офиса Лабытнанги.

| Eq  | Destination              | Gateway                | Comment (name)                    |
|-----|--------------------------|------------------------|-----------------------------------|
| R1  | 0.0.0.0/0                | 172.16.19.1            | to R19 (ISP)                      |

### Пример настройки статического маршрута

```
conf t
 ip route 0.0.0.0 0.0.0.0 172.16.19.1
exit
```
